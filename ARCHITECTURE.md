# Architecture

```
.env files ──► env/parse ──► connectors[].detect ──► Secret[]
                                                       │
                     connectors[].check(secret, ctx) ◄─┘
                       │  ctx.fetch = safeFetch bound to the connector allowlist
                       ▼
                   Finding[] ──► risk/aggregate ──► report/{terminal,json} ──► guard ──► stdout
```

| Path | Responsibility |
| --- | --- |
| `src/cli.ts` | Argument parsing, exit codes, wiring. `main(argv, io)` is pure enough to test in-process. |
| `src/scan.ts` | Runs every connector over the parsed env; turns connector errors into `unknown` findings. |
| `src/env/parse.ts` | Small dotenv parser (no expansion). Never logs or echoes lines. |
| `src/secret.ts` | `Secret` wraps a value: redacted `toString`/`toJSON`/`inspect`, `allowedHost()`, `hint()`. |
| `src/net/safeFetch.ts` | The only network primitive. Allowlist of method + host + path; GraphQL by document hash; no redirects; optional `discardBody`. |
| `src/connectors/types.ts` | The `Connector` interface. |
| `src/connectors/<id>.ts` | One file per provider, exporting `connector`; the file name is the id. `example.ts` is the template; it is test-only and never registered. |
| `src/connectors/index.ts` | Registry, built from `registry.generated.ts`. |
| `src/connectors/registry.generated.ts` | Generated by `scripts/gen-connectors.mjs` before build, typecheck, lint and test, and by Vitest's `globalSetup` for any test runner. Not committed, so connector PRs never touch a shared file. |
| `src/risk/aggregate.ts` | Per-secret roll-up (worst level, weakest confidence) and summary. |
| `src/report/` | Terminal and JSON renderers, plus `guard.ts`, the last-line leak check. |
| `scripts/` | Build and development helpers (connector registry generator). Not shipped. |

## Invariants (each one has a test or lint rule)

1. Only `src/net/safeFetch.ts` touches the network (`eslint.config.js`, `test/lint-rules.test.ts`).
2. No mutating method can be allowlisted; POST only for hashed read-only GraphQL (`test/safe-fetch.test.ts`).
3. A secret is only sent to its own `allowedHosts`, never in a URL (`test/safe-fetch.test.ts`).
4. No secret value reaches stdout, stderr or JSON (`test/canary.test.ts`, `src/report/guard.ts`).
5. Unknown stays unknown: failed checks become `amber/unknown`, never `green` (`src/scan.ts`, `src/risk/aggregate.ts`).
6. Only real connectors are registered: ids are unique, file name equals id, `example` is never registered (`test/registry.test.ts`).

## Out of scope for v0.1

CLI session files (`~/.config/gh`, `~/.vercel`, ...), more providers
(Supabase, AWS, Railway...), the GitHub Action and `--fix`. Reading CLI
sessions will require an explicit opt-in flag.
